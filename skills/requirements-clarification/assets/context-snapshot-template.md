# Context snapshot template

Use this template only before mode selection.

```markdown
## Context Snapshot

### Confirmed
- <fact, decision, constraint, or success criterion explicitly supplied or approved>

### Assumptions
- <reasonable interpretation that still needs confirmation>

### Gaps or conflicts
- <missing or contradictory information that changes scope, cost, permissions, data, security, integration, failure behavior, or acceptance>

### Sources consulted
- <conversation, user-provided file, or linked source + read/failure state>
```
